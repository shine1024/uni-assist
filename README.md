# Uni-Assist 도우미 (Chrome 확장)

웹 업무 생산성을 돕는 크롬 확장 도우미입니다. UI는 **사이드 패널**로 동작해, 페이지를 클릭하는 동안에도 닫히지 않습니다.
사이드 패널 상단 메뉴에서 기능을 전환합니다.

| 메뉴 | 기능 |
|---|---|
| 🔤 텍스트 추출 | 여러 요소에서 텍스트 추출 → 정규식 가공 → 조합 → 복사 (+ 허용 사이트 전용 단축키 복사) |
| 🔐 자동 로그인 | 사이트별 ID/PW 등록 → 단축키(기본 `F2`) 한 번으로 **로그인, 로그인 상태면 로그아웃**. AES-256-GCM 암호화 + PC 간 동기화 |
| 🔑 2차 인증 OTP | 메일함에서 **2차 인증번호를 가져와** 복사하거나 현재 탭에 입력 (Native Messaging) |
| ⚙ 설정 | 마스터 비밀번호·자동 잠금, 동기화 상태, 단축키 |

패널 열기/닫기는 **`F4`** 입니다 (설정에서 변경 가능).

## 텍스트 추출 — 주요 기능

웹페이지의 **여러 요소에서 텍스트를 추출 → 정규식으로 가공 → 원하는 형태로 조합 → 복사**합니다.

- 🖱 **요소 클릭 선택** — 페이지에서 마우스로 요소를 골라 추출 대상으로 지정 (ESC로 취소)
- ➕ **다중 선택 & 조합** — 여러 요소를 규칙(rule)으로 추가하고 순서대로 조합
- 🔤 **정규식 변환** — 규칙마다 여러 단계의 찾기/바꾸기(리터럴 또는 정규식)를 적용
- 🧩 **조합 모드 2종**
  - `연결`: 구분자(없음/공백/줄바꿈/탭/쉼표/직접입력)로 이어붙이기
  - `템플릿`: `[{1}] {2} - {3}` 처럼 위치·고정문구를 자유롭게 배치
- 💾 **프리셋** — 자주 쓰는 추출 구성을 이름 붙여 저장/불러오기
- ♻ **자동 저장 & 재추출** — 작업 상태는 자동 저장되고, `↻ 재추출`로 현재 페이지 값으로 갱신
- ⌨ **단축키 복사 (특정 사이트 전용)** — 허용한 사이트에서만 단축키를 누르면, 사이드 패널을 열지 않아도 현재 페이지에서 재추출→조합→**자동 클립보드 복사** (페이지에 "복사됨 ✓" 토스트 표시)

## 설치 (개발자 모드 로드)

1. Chrome 주소창에 `chrome://extensions` 입력
2. 우측 상단 **개발자 모드** 켜기
3. **압축해제된 확장 프로그램을 로드합니다** 클릭 → 이 폴더(`uni-assist`) 선택
4. 툴바의 ⛏ 아이콘 클릭 → 사이드 패널이 열림 (고정하려면 아이콘 우클릭 → 핀)

> Chrome 114 이상 필요 (사이드 패널 API). 아이콘을 다시 만들려면 `python tools/make_icons.py`.

## 사용법

1. 텍스트를 추출할 페이지를 연다.
2. 사이드 패널에서 **＋ 요소 선택** → 페이지에서 원하는 요소를 클릭.
3. 규칙 카드에서 가공:
   - **변환 추가**로 찾기/바꾸기 단계를 쌓는다. `정규식` 체크 시 플래그(`gi` 등) 사용 가능.
   - 추출 소스 선택: `텍스트` / `텍스트(숨김포함)` / `입력값` / `속성`(예: `href`).
4. 2~3을 반복해 여러 요소를 추가.
5. **조합 결과** 영역에서 모드/구분자/템플릿을 정하고 **📋 복사**.

### 예시 — 요구사항 시나리오

> 1번 요소 추출(앞의 "일감" 제거) + 2번 요소 추출 → 조합

- **규칙 ①**: 제목 요소 선택 → 변환 `찾기: 일감`, `바꿀내용: (비움)` → 결과 `배포작업`
- **규칙 ②**: 날짜 요소 선택 → 변환 없음 → 결과 `2026-06-29`
- **조합(연결, 공백)** → `배포작업 2026-06-29` → 복사

정규식으로 앞쪽만 제거하려면 `찾기: ^일감\s*`, `정규식` 체크.

### 단축키로 특정 사이트에서만 복사

1. 사이드 패널 **단축키 복사** 영역에서 **허용 사이트 패턴**을 입력 (한 줄에 하나, `*` 와일드카드).
   - 기본값: `https://labdev.unipost.co.kr/redmine` → 이 경로(및 하위 경로)에서만 동작.
2. 대상 사이트에서 조합할 규칙들을 만들어 둔다(작업 상태는 자동 저장됨).
3. 그 사이트에서 **단축키(기본 `Ctrl+Shift+Y`, Mac `⌘+Shift+Y`)** 를 누르면 → 조합 결과가 클립보드에 복사되고 페이지에 "복사됨 ✓"가 뜬다.
   - 허용 사이트가 아니면 아무 일도 일어나지 않는다(전역 단축키지만 URL로 게이트).
   - 단축키 변경: **단축키 변경…** 버튼 → `chrome://extensions/shortcuts`.

> ⚠ 매니페스트(권한·단축키)를 바꾼 뒤에는 `chrome://extensions`에서 확장을 **새로고침**해야 적용됩니다.
> 제안 단축키가 다른 확장과 충돌하면 자동 등록되지 않을 수 있으니, 그때는 위 shortcuts 페이지에서 직접 지정하세요.

## 자동 로그인 / 로그아웃 — 주요 기능

사이트별로 로그인 정보를 등록해 두고, 그 사이트에서 **단축키(기본 `F2`)** 를 누르면
아이디/비밀번호 입력 → 로그인 버튼 클릭까지 자동으로 실행합니다.
**이미 로그인된 상태라면 같은 키로 로그아웃**합니다.

- 🔁 **같은 키로 로그인/로그아웃** — 등록한 "로그아웃 요소"가 페이지에 있으면 로그아웃, 없으면 로그인
- 🗂 **다중 사이트 · 다중 계정** — 사이트마다 계정을 여러 개 등록. 2개 이상이면 **실행할 때마다 선택창**이 뜬다
- 🎯 **정확한 주소 매칭** — origin(프로토콜+도메인+**포트**) 완전 일치 + 경로 단위 구분 (`/admin/login` 과 `/login` 을 다르게 취급)
- 🖱 **요소 클릭으로 Selector 지정** — 텍스트 추출과 같은 선택기를 재사용. `id`·`name`·`data-*` 등 안정적인 속성을 우선 사용
- ⚛ **React/Vue 대응** — 네이티브 setter로 값을 넣고 `input`/`change` 이벤트를 발생시켜 제어 컴포넌트에도 반영
- ⏳ **동적 로그인 폼 대기** — MutationObserver로 입력창이 생길 때까지 대기(기본 8초 타임아웃)
- 🔐 **마스터 비밀번호 잠금** — 해제 후 기본 1시간 동안만 동작(1·4·8시간 선택), 수동 잠금·자동 잠금 시간 변경 가능
- ☁ **PC 간 동기화** — 암호화된 상태로 `chrome.storage.sync` 를 통해 같은 구글 계정의 다른 PC로 전달

### 쓰는 순서

1. 사이드 패널 → **🔐 자동 로그인** → 최초 1회 **마스터 비밀번호 설정**(8자 이상).
2. 로그인 페이지를 열어 둔 상태에서 **+ 사이트** (현재 탭 주소·제목이 자동 입력됨).
3. **입력 요소** 카드에서 **순서대로 선택** → 페이지에서 아이디 → 비밀번호 → 로그인 버튼을 차례로 클릭.
   - 직접 Selector를 입력해도 되고, **현재 탭에서 확인** 으로 찾히는지 검사할 수 있습니다.
4. **+ 계정** 으로 아이디/비밀번호를 입력하고 **저장** (저장 시 암호화됩니다).
5. 그 사이트에서 **`F2`** → 자동 로그인. 계정이 여러 개면 페이지에 선택창이 뜹니다.
6. (선택) 로그인된 상태에서 **로그아웃** 카드의 **선택** 을 눌러 로그아웃 링크를 지정하면,
   이후 로그인 상태에서 `F2` 를 누르면 로그아웃합니다.

### 계정이 여러 개일 때

| 계정 수 | `F2` 를 누르면 |
|---|---|
| 1개 | 바로 로그인 |
| 2개 이상 | 페이지에 **선택창** → `Enter`(먼저 지정한 계정) / `숫자키` / `↑↓`+`Enter` / `ESC` 취소 |

**먼저** 라디오로 지정한 계정은 선택창 맨 위에 포커스된 상태로 올라와서 `Enter` 한 번이면 실행됩니다.
선택창을 건너뛰지는 않습니다 — 건너뛰면 나머지 계정을 쓸 방법이 없기 때문입니다.

### 로그인/로그아웃 판별

로그아웃 셀렉터로 지정한 요소가 **페이지에 존재하면 로그인된 상태**로 보고 로그아웃을, 없으면 자동 로그인을 실행합니다.

- 로그아웃 링크처럼 **로그인했을 때만 생기는 요소**를 고르세요. 드롭다운 안에 숨어 있어도 됩니다(표시 여부는 보지 않음).
- 로그아웃은 복호화가 필요 없어서 **잠금 상태에서도 동작**합니다.
- 비워 두면 로그아웃을 하지 않고 항상 로그인만 시도합니다. 사이트별로 끌 수도 있습니다.
- 로그아웃된 상태에도 그 요소가 DOM에 남는 사이트라면, 로그인 상태에서만 생기는 다른 요소
  (사용자 이름 영역 등)를 셀렉터로 쓰세요.

### 주소 매칭 범위 — 로그인과 로그아웃이 다릅니다

| | 매칭 조건 |
|---|---|
| **로그인** | origin(프로토콜+도메인+**포트**) 완전 일치 + (경로 일치를 켠 경우) 경로 일치 |
| **로그아웃** | origin 완전 일치만 — **경로는 보지 않음** |

로그인은 특정 경로(로그인 페이지)에서 하지만 로그아웃은 로그인 후 이동한 아무 경로에서나 누르기 때문입니다.

**경로까지 일치**는 기본 **꺼짐**입니다. 같은 도메인에 앱이 여러 개라 구분이 필요할 때만 켜세요.
켜면 등록한 URL의 경로 및 그 하위에서만 **로그인**합니다 — 로그인 페이지 경로(`/login` 등)로 등록했다면
로그인 후에는 그 경로를 벗어나므로 URL을 앱 루트(예: `/redmine`)로 고치는 게 좋습니다.

## 단축키

| 종류 | 기본값 | 동작 범위 | 구현 |
|---|---|---|---|
| 로그인 / 로그아웃 | **`F2`** | 페이지에 포커스가 있을 때 | 페이지 내 리스너 |
| 사이드 패널 열기 / 닫기 | **`F4`** | 페이지에 포커스가 있을 때 | 페이지 내 리스너 |
| 로그인 (전역) | `Ctrl+Shift+L` (Mac `⌘+Shift+L`) | 브라우저 어디서든(주소창 포함) | Chrome `commands` API |
| 조합 결과 복사 (전역) | `Ctrl+Shift+Y` (Mac `⌘+Shift+Y`) | 허용 사이트 패턴에서 | Chrome `commands` API |

### 왜 `F2`/`F4` 는 따로 구현했나

Chrome `commands` API는 **`Ctrl` 또는 `Alt` 를 반드시 포함**해야 하고, 지원 키 목록에
**`F1`~`F12` 가 없습니다**(공식 문서). 즉 `F2`/`F4` 단독 키는 `chrome://extensions/shortcuts` 에서도 등록할 수 없습니다.
→ 작은 키 리스너(`src/content/hotkey.js`)를 `chrome.scripting.registerContentScripts()` 로 심어 처리합니다.

- 기본값은 **모든 http(s) 페이지**입니다 (패널 토글을 어디서든 쓸 수 있도록).
  설정의 **모든 사이트에서 사용** 을 끄면 **등록된 로그인 사이트에만** 리스너를 심습니다(범위 최소화, 이때 `F4` 도 그 사이트에서만 동작).
- 사이트를 추가·수정·삭제하거나 단축키 설정을 바꾸면 자동으로 다시 등록됩니다.
- 주소창 등 **브라우저 UI에 포커스가 있으면 동작하지 않습니다** (로그인은 전역 단축키로 대체 가능).
- 수정자 없는 **일반 글자키**를 지정하면 입력창에 포커스가 있을 때는 무시합니다(글자 입력을 막지 않기 위함).
  `F2`/`F4` 같은 기능키는 입력창에서도 동작합니다.
- 페이지가 같은 키를 쓰는 경우(예: 그리드 인라인 편집) 충돌할 수 있습니다 → 설정에서 다른 키로 바꾸세요.
- 설정 → 단축키에서 **키 지정** 버튼을 누르고 원하는 키를 누르면 됩니다. 각각 끌 수도 있습니다.

> ⚠ **패널 닫기는 Chrome 141+** 에서만 됩니다(`chrome.sidePanel.close()` 가 Chrome 141에 추가됨).
> 그 이전 버전에서는 `F4` 로 열기만 되고, 닫을 때는 안내 메시지가 표시됩니다.

### 보안 설계

| 항목 | 내용 |
|---|---|
| 암호화 | AES-256-GCM, 레코드마다 **고유 IV**(96bit), salt/IV는 `crypto.getRandomValues` |
| 키 유도 | PBKDF2-HMAC-SHA256, **600,000회**(OWASP 권장치), 반복 횟수를 레코드에 기록해 추후 상향 가능 |
| 마스터 비밀번호 | **저장하지 않음.** 알려진 평문을 암호화한 검증자(verifier)의 복호화 성공 여부로만 확인 |
| 잠금 해제 키 | `chrome.storage.session`(인메모리, 디스크 미기록, 콘텐츠 스크립트 접근 불가, 동기화 제외). 브라우저 종료 시 소멸 |
| 주입 범위 | 등록 origin과 **완전히 일치**할 때만, **최상위 프레임에만** 주입. 주입 직후 콘텐츠 스크립트가 `location.origin` 재확인 |
| 다운그레이드 차단 | HTTPS로 등록한 사이트를 HTTP로 접속하면 실행하지 않고 이유를 안내 |
| 비밀번호 취급 | 평문 저장·콘솔 출력 없음, 복사 기능 없음, 저장 직후 메모리에서 폐기, 비밀번호 입력창의 기존 값은 추출 대상에서 제외 |
| 동기화 경합 방지 | 사이트는 동기화됐는데 금고 정보가 아직 안 온 상태에서는 **"최초 설정"을 차단** (새 금고로 덮어쓰면 기존 암호문을 영구히 잃음) |
| 원인 진단 | 암호문마다 **키 지문**(키 SHA-256 앞 6바이트)을 기록해, 복호화 실패 시 "손상"과 "다른 마스터 비밀번호로 암호화됨"을 구분 |
| 추가 인증 | 자동 로그인 메뉴는 CAPTCHA·MFA·Passkey를 **다루지 않고** 1차 자격증명까지만 자동화. 메일 인증번호 입력은 **🔑 2차 인증 OTP 메뉴에서 버튼을 눌렀을 때만** 수행 |

> ⚠ 마스터 비밀번호는 어디에도 저장되지 않습니다. **분실하면 저장된 비밀번호를 복구할 수 없습니다.**
> 변경 시에는 저장된 모든 비밀번호를 새 키로 다시 암호화합니다.

### PC 간 동기화 조건

- 두 PC에서 **같은 구글 계정으로 로그인 + 크롬 동기화 ON** 이어야 하고, 각 PC에서 **같은 마스터 비밀번호**를 입력해야 복호화됩니다.
  - `salt`가 동기화되므로 같은 마스터 비밀번호면 같은 키가 유도됩니다. 키 자체는 어디에도 저장되지 않습니다.
  - 다른 비밀번호를 입력하면 `verifier` 검증에서 **잠금 해제가 거부**됩니다(반쯤 열리는 상태는 없습니다).
- ⚠ **새 PC를 붙일 때는 동기화가 끝난 뒤 기존 마스터 비밀번호를 입력하세요.** 아직 도착하지 않은 상태에서
  새로 설정하면 기존 비밀번호를 열 수 없게 되므로, 그런 상태를 감지하면 설정을 막고 안내합니다.
- 동기화는 **확장 프로그램 ID가 같을 때만** 공유됩니다. 압축해제 로드는 원래 폴더 경로에 따라 ID가 달라지므로,
  `manifest.json` 의 `key` 로 ID를 **`fjmhmlhmfiomcjplmoehjmjbfeehhmmj`** 로 고정해 두었습니다. 어느 PC, 어느 폴더에 받아도 같은 ID입니다.
  - 고정 전 버전을 쓰던 PC는 ID가 바뀌어 기존 데이터가 보이지 않습니다. 이전 버전에서 **설정 → 백업 → 내보내기** 한 파일을
    새 버전에서 **가져오기** 하고, OTP 호스트 설치 스크립트를 한 번 다시 실행하세요.
- 용량 제한(Chrome 공식): 전체 **100KB**, 항목당 **8KB**, 최대 512항목. 사이트 1개 = sync 항목 1개로 나눠 저장합니다.
  설정 → 동기화 카드에서 현재 사용량을 볼 수 있습니다.

## 2차 인증 OTP 가져오기

사이드 패널 **🔑 2차 인증 OTP → 인증번호 확인** 을 누르면 가장 최근 인증 메일의 번호와 수신 시각을 보여 줍니다.

- **📋 복사**: 인증번호를 클립보드에 복사합니다.
- **입력 후 확인**: 현재 탭의 `input.fid-authPass` 에 입력하고 `.bid-confirm` 을 누릅니다.

이전 메일의 번호일 수 있으니 수신 시각을 확인하세요. 셀렉터는 `src/lib/approval-config.js` 에 있고, 고친 뒤에는 `chrome://extensions` 에서 확장을 새로고침합니다.

크롬 확장은 POP3 에 직접 접속할 수 없어, 로컬 Node 프로그램(`host/`)을 Native Messaging 으로 호출합니다.
호스트를 설치하지 않아도 다른 기능은 그대로 동작합니다.

### 설치 (macOS / Windows 각 PC에서 1회)

Node.js 20.11 이상이 필요합니다. 설치 중 **확장 ID** 를 물으면 Enter 로 고정 ID를 쓰면 됩니다(사이드 패널 **2차 인증** 메뉴에도 표시됩니다).

```bash
bash install/install-mac.sh                                          # macOS
powershell -ExecutionPolicy Bypass -File install\install-win.ps1     # Windows
```

스크립트가 의존성 설치, 호스트 등록, 메일 비밀번호의 OS 키체인 저장(입력 숨김)을 처리합니다.
제거는 macOS `--uninstall`, Windows `-Uninstall` 입니다. Node 를 업그레이드했거나 폴더를 옮겼다면 다시 실행하세요.

### 설정 (`host/config.json`)

| 값 | 내용 |
|---|---|
| `pop3.host` / `pop3.user` | POP3 호스트와 메일 계정. 한비로는 **전체 메일 주소**를 씁니다 |
| `otp.from` | 인증 메일 발신 주소 |
| `otp.subjectPattern` | 제목 **정규식**. `[`, `]` 는 `\\[`, `\\]` 로 이스케이프합니다 |
| `otp.codePattern` | 본문에서 번호를 찾는 정규식 |

`host/config.json` 은 사내 정보가 저장소에 올라가지 않도록 git 에서 제외했습니다. PC마다 따로 채웁니다.
`config.example.json` 에 사내 공통값(호스트·발신 주소·제목·번호 패턴)이 들어 있으니 복사한 뒤 `pop3.user` 만 본인 메일 주소로 바꾸면 됩니다.
제목 패턴 예: `"\\[유니포스트\\] 로그인 2차 인증 번호 발급 안내"` — 대괄호를 이스케이프하지 않으면 어떤 메일과도 일치하지 않습니다.
비밀번호는 키체인에만 저장하며 이 파일에 넣지 않습니다.

### 문제 해결

| 안내 | 조치 |
|---|---|
| 호스트에 연결하지 못했어요 | 설치 스크립트 실행, 확장 ID 일치 확인 |
| 키체인에 메일 비밀번호가 없어요 | 설치 스크립트로 등록 |
| 메일 로그인에 실패했어요 | `pop3.user` 가 전체 주소인지 확인, 비밀번호 재등록 (`node host/setup-credentials.js`) |
| 메일 서버에 접속하지 못했어요 | 호스트 주소, 995 포트, 사내망·VPN, 인증서 확인 |
| 최근 메일에서 인증 메일을 찾지 못했어요 | 발신 주소, 제목 패턴의 대괄호 이스케이프 확인 |
| 입력칸·확인 버튼을 찾지 못했어요 | 인증번호 화면 탭이 활성 상태인지, `approval-config.js` 셀렉터가 맞는지 확인 |

메일 서버의 "가져간 메일 삭제" 설정은 꺼 두어야 합니다. 이 도구는 메일을 지우지 않지만 서버 설정까지 막을 수는 없습니다.
사용 전 사내 보안 정책상 2차 인증 자동화가 허용되는지 확인하세요.
