# Uni-Assist 도우미 (Chrome 확장)

웹 업무 생산성을 돕는 크롬 확장 도우미입니다. UI는 **사이드 패널**로 동작해, 페이지를 클릭하는 동안에도 닫히지 않습니다.
앞으로 여러 기능을 추가해 나갈 예정이며, 현재 첫 기능은 **텍스트 추출**입니다.

## 텍스트 추출 — 주요 기능

웹페이지의 **여러 요소에서 텍스트를 추출 → 정규식으로 가공 → 원하는 형태로 조합 → 복사**합니다.

- 🖱 **요소 클릭 선택** — 페이지에서 마우스로 요소를 골라 추출 대상으로 지정 (ESC로 취소)
- ➕ **다중 선택 & 조합** — 여러 요소를 규칙(rule)으로 추가하고 순서대로 조합
- 🔤 **정규식 변환** — 규칙마다 여러 단계의 찾기/바꾸기(리터럴 또는 정규식)를 적용
- 🧩 **조합 모드 2종**
  - `연결`: 구분자(없음/공백/줄바꿈/탭/쉼표/직접입력)로 이어붙이기
  - `템플릿`: `[{1}] {2} - {3}` 처럼 위치·고정문구를 자유롭게 배치
- 💾 **프리셋** — 자주 쓰는 추출 구성을 이름 붙여 저장/불러오기
- ♻ **자동 저장 & 재추출** — 작업 상태는 자동 저장되고, `↻ 재추출`로 현재 페이지 값으로 갱신
- ⌨ **단축키 복사 (특정 사이트 전용)** — 허용한 사이트에서만 단축키를 누르면, 사이드 패널을 열지 않아도 현재 페이지에서 재추출→조합→**자동 클립보드 복사** (페이지에 "복사됨 ✓" 토스트 표시)

## 설치 (개발자 모드 로드)

1. Chrome 주소창에 `chrome://extensions` 입력
2. 우측 상단 **개발자 모드** 켜기
3. **압축해제된 확장 프로그램을 로드합니다** 클릭 → 이 폴더(`uni-assist`) 선택
4. 툴바의 ⛏ 아이콘 클릭 → 사이드 패널이 열림 (고정하려면 아이콘 우클릭 → 핀)

> Chrome 114 이상 필요 (사이드 패널 API). 아이콘을 다시 만들려면 `python tools/make_icons.py`.

## 사용법

1. 텍스트를 추출할 페이지를 연다.
2. 사이드 패널에서 **＋ 요소 선택** → 페이지에서 원하는 요소를 클릭.
3. 규칙 카드에서 가공:
   - **변환 추가**로 찾기/바꾸기 단계를 쌓는다. `정규식` 체크 시 플래그(`gi` 등) 사용 가능.
   - 추출 소스 선택: `텍스트` / `텍스트(숨김포함)` / `입력값` / `속성`(예: `href`).
4. 2~3을 반복해 여러 요소를 추가.
5. **조합 결과** 영역에서 모드/구분자/템플릿을 정하고 **📋 복사**.

### 예시 — 요구사항 시나리오

> 1번 요소 추출(앞의 "일감" 제거) + 2번 요소 추출 → 조합

- **규칙 ①**: 제목 요소 선택 → 변환 `찾기: 일감`, `바꿀내용: (비움)` → 결과 `배포작업`
- **규칙 ②**: 날짜 요소 선택 → 변환 없음 → 결과 `2026-06-29`
- **조합(연결, 공백)** → `배포작업 2026-06-29` → 복사

정규식으로 앞쪽만 제거하려면 `찾기: ^일감\s*`, `정규식` 체크.

### 단축키로 특정 사이트에서만 복사

1. 사이드 패널 **단축키 복사** 영역에서 **허용 사이트 패턴**을 입력 (한 줄에 하나, `*` 와일드카드).
   - 기본값: `https://labdev.unipost.co.kr/redmine` → 이 경로(및 하위 경로)에서만 동작.
2. 대상 사이트에서 조합할 규칙들을 만들어 둔다(작업 상태는 자동 저장됨).
3. 그 사이트에서 **단축키(기본 `Ctrl+Shift+Y`, Mac `⌘+Shift+Y`)** 를 누르면 → 조합 결과가 클립보드에 복사되고 페이지에 "복사됨 ✓"가 뜬다.
   - 허용 사이트가 아니면 아무 일도 일어나지 않는다(전역 단축키지만 URL로 게이트).
   - 단축키 변경: **단축키 변경…** 버튼 → `chrome://extensions/shortcuts`.

> ⚠ 매니페스트(권한·단축키)를 바꾼 뒤에는 `chrome://extensions`에서 확장을 **새로고침**해야 적용됩니다.
> 제안 단축키가 다른 확장과 충돌하면 자동 등록되지 않을 수 있으니, 그때는 위 shortcuts 페이지에서 직접 지정하세요.

## 폴더 구조

```
uni-assist/
├─ manifest.json              # MV3 매니페스트
├─ icons/                     # 아이콘 (tools/make_icons.py 로 생성)
├─ src/
│  ├─ background/service-worker.js   # 패널 열기 + 단축키→추출·조합·복사 (ES 모듈)
│  ├─ content/picker.js + .css       # 페이지 요소 선택/추출/토스트 (콘텐츠 스크립트)
│  ├─ sidepanel/                     # 사이드 패널 UI (html/css/js)
│  ├─ offscreen/                     # 서비스 워커용 클립보드 복사 문서
│  └─ lib/                           # 순수 로직: transform.js(변환·조합), match.js(URL 매칭)
├─ tools/
│  ├─ make_icons.py           # 아이콘 생성기 (의존성 없음)
│  └─ test-transform.mjs      # 변환 로직 테스트 (node tools/test-transform.mjs)
└─ docs/                      # 개발 이력 / 작업 세션 관리 → docs/CONTINUE-HERE.md 참고
```

## 테스트

```bash
node tools/test-transform.mjs
```
