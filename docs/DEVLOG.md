## 2026-06-29  v0.2.0 — 단축키 복사 (특정 사이트 전용)
- `commands` API로 단축키 `copy-combined`(기본 Ctrl+Shift+Y) 추가
- 서비스 워커를 ES 모듈로 전환, 단축키 시 현재 탭 URL이 허용 패턴과 일치할 때만 동작하도록 게이트
- 동작: 저장된 규칙으로 현재 페이지 일괄 재추출(`EXTRACT_ALL`) → 변환·조합 → 클립보드 복사
- 서비스 워커는 클립보드 직접 접근 불가 → `offscreen` 문서(`src/offscreen/*`)로 복사
- 콘텐츠 스크립트에 `EXTRACT_ALL`, `TOAST`(페이지 "복사됨 ✓") 추가
- URL 매칭 로직 분리(`src/lib/match.js`) + 테스트 7종 추가(총 18종 통과)
- 사이드 패널에 "단축키 복사" 설정 영역(허용 사이트 패턴 편집, 현재 단축키 표시, 변경 링크) 추가
- 권한 추가: `offscreen`, `clipboardWrite`

## 2026-06-29  v0.1.0 — 최초 골격 + 기본 기능
- 프로젝트 초기화, 폴더 구조/세션 관리 문서 체계 구성 (`docs/`)
- MV3 매니페스트 + 백그라운드(아이콘 클릭→사이드 패널) 작성
- 콘텐츠 스크립트(`picker.js`): 요소 호버 하이라이트, 클릭 선택, 셀렉터 생성, 텍스트/속성/입력값 추출
- 사이드 패널 UI: 규칙 다중 추가, 다단계 정규식 변환, 연결/템플릿 조합, 복사, 프리셋, 자동 저장
- 변환·조합 로직 분리(`src/lib/transform.js`) + 단위 테스트 11종 (전부 통과)
- 무의존 아이콘 생성기(`tools/make_icons.py`)로 16/48/128 PNG 생성
- 세션 관리 진입 문서 `docs/CONTINUE-HERE.md` 작성
- 상태: 코드 레벨 완성. 실제 크롬 로드 후 수동 검증은 미실시(다음 세션 과제).
