# 세션 기록 — 2026-11-10 (session-03)

## 목표
개발 지시서의 결재 시스템 자동 로그인을 Uni-Assist 기능으로 추가.

## 결정 / 배운 점
- 독립 확장이 아니라 통합. S7 은 `<all_urls>` 유지 + 결재 origin 입력 제한 + 네이티브 호출 서비스 워커 전용으로 대체.
- node-pop3 는 명령 대기 중 소켓이 끊기면 약속이 끝나지 않는다. 접속 단위 제한시간과 소켓 정리를 `withSession` 에 넣었다.
- 로그인 완료는 "로그인 화면이 아님"이 아니라 결재대기함 일치로 판단한다. 인증 화면이 열린 탭은 이동시키지 않는다.
- 인증번호 재시도는 재발송 버튼(`otpResend`)을 지정했을 때만 1회 한다. 없으면 새 메일이 오지 않기 때문.
- 메일함 잠금 응답은 인증 실패가 아니라 재시도 대상으로 분류한다.
